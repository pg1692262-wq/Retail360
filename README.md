# Retail360

### De los datos a las decisiones comerciales

*Proyecto final — Visualización de Datos | ADMI-1301*

## Descripción del proyecto

Retail360 es una herramienta de análisis y visualización de datos comerciales desarrollada en Python que facilita la interpretación de información de ventas y la toma de decisiones empresariales.

## Objetivo principal

Analizar y comparar el comportamiento comercial de tres productos mediante indicadores de ingresos, unidades vendidas, crecimiento mensual y recurrencia de clientes, con el propósito de identificar oportunidades comerciales.

## Funcionalidades

- Revisión y preparación de datos.
- Comparación de indicadores por producto.
- Análisis de la evolución mensual de las ventas.
- Identificación de compras de alto valor.
- Análisis de clientes recurrentes.
- Panel interactivo con filtros por mes, producto e indicador.
- Validación de resultados mediante 12 controles internos.
- Generación de recomendaciones comerciales.

## Hallazgos comerciales

- El soporte para tortas genera aproximadamente el 50 % de los ingresos totales.
- El portavelas representa aproximadamente el 67 % de las unidades vendidas.
- El soporte para tortas presentó un crecimiento del 93,55 % entre febrero y marzo.
- La mayor factura del portavelas representa el 20,05 % de sus ingresos.

## Recomendación comercial

Priorizar el soporte para tortas según los indicadores disponibles, mantener el portavelas como producto de volumen y evaluar oportunidades de crecimiento para el juego de latas.

## Limitaciones

La información disponible no incluye costos ni inventarios. Por lo tanto, el análisis permite comparar ingresos y desempeño comercial, pero no determinar la rentabilidad de los productos ni establecer patrones de estacionalidad.
